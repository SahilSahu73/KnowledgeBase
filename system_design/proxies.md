# Proxy vs Reverse Proxy
Refer to this link for detailed explanation:
[Algomaster_blog](https://blog.algomaster.io/p/proxy-vs-reverse-proxy-explained)

They are basically servers that sit b/w clients and servers to improve security, privacy and 
performance.

Proxy server (Forward proxy) - acts on behalf of clients
Reverse Proxy - acts on behalf of servers.
