# Transport Layer Security (TLS)
- Security protocol for communication over the internet.
- Primary use case: encrypting communication b/w web apps and servers.
- TLS / SSL certificate - digital credential - issued by a certificate authority (CA) - verifies a websites identity and enables an encrypted connection.
- TLS ensures secure Internet communication by enforcing 3 core properties of a secure channel:
    - **Authentication**: verifies the senders and receivers identities, and the origin and destination of the data.
    - **Confidentiality**: Ensures data can only be accessed by intended recipients.
    - **Integrity**: Ensures data cannot be modified in storage or transmission without changes being detected.

TLS relies on cryptographic processes to secure transmitted info.
