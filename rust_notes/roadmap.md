# Learning Roadmap
1. The Rust Programming language Book - [link](https://doc.rust-lang.org/book/ch01-00-getting-started.html)
2. Solve rustlings - it is github repo with snippet of codes that needs to be completed and pass the test cases set.
Its a fun code completion exercises - [link](https://rustlings.rust-lang.org/)
3. Then go to neetcode and solve the initial few topics like array and hashing, two pointers, stack,....etc.
[link](https://neetcode.io/roadmap)
4. Then try exercism, wherein learn through solving coding problems and projects - [link](https://exercism.org/tracks/rust)
5. Finally if still don't have any project ideas then just start reading this book: Zero to production backend development in Rust.
Very comprehensive book to learn backend engineering.
Downloaded and saved in the books folder.
